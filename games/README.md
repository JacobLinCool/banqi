# 自我對弈棋譜

網路上找不到公開的台灣暗棋棋譜（暗棋隨機性高，PTT DarkChess 版與巴哈姆特社群都沒有收集棋譜的傳統；電腦比賽也只公布戰績），所以這裡的棋譜由本引擎自我對弈產生：雙方都是 MoE 引擎（多變模式），每步思考 1 秒。

每個檔案包含：
- 牌局種子與初始蓋牌配置（引擎對局時看不到，僅供覆盤）
- 每一步的著法、引擎評分（從該步走棋方的角度，約 100 ≈ 一個小子；±20000 附近為殘局資料庫必勝 / 必敗，±30000 附近為搜尋到的殺棋）與搜尋深度
- 最終盤面

座標：a–h 由左至右，1–4 由下至上。記法：`c3 翻 俥`（翻子）、`c3-c4`（走子）、`c3xc4 吃 馬`（吃子）。

重新產生：`cd engine && cargo run --release --bin records -- 24 1000 ../games 4`
